# ROGII — Wellbore Geology Prediction (Kaggle)

Рабочий репозиторий по соревнованию [ROGII - Wellbore Geology Prediction](https://www.kaggle.com/competitions/rogii-wellbore-geology-prediction).

## Суть задачи

Нужно предсказать `TVT` (True Vertical Thickness — положение горизонтального
ствола скважины в стратиграфической колонке) для "слепой" (ещё не
проинтерпретированной) части каждой скважины. Известны: траектория
(`MD/X/Y/Z`), гамма-каротаж (`GR`) вдоль всего ствола, известная часть `TVT`
у "пятки" скважины, и эталонный вертикальный разрез (`typewell`: `TVT` vs
`GR` vs `Geology`). Метрика — pooled RMSE в футах по всем строкам теста.

По факту задача сводится к сопоставлению GR-сигнатуры горизонтальной
скважины с эталонным разрезом (geosteering / geological correlation), а не
к обычной табличной регрессии.

## Что проверено (честная валидация, pooled RMSE)

- **Flat baseline** (протянуть последнее известное `TVT`): pooled RMSE ≈ **15.9**
  (совпадает с реальным carry-last baseline на паблик-лидерборде: 15.883).
- **Наивная корреляция GR** (Pearson-окна без калибровки): проваливается,
  локализация правильной глубины — единицы процентов.
- **Heel-калиброванный GR-мэтчинг** (линейная регрессия GR→typewell на
  известной части): локализация датума до ~77-80%, близко к oracle-потолку.
- **GR rotation-band denoising** (notch-фильтр ~6.5 фт период): небольшое,
  но стабильное и устойчивое к параметрам улучшение (+0.4-0.8 п.п.
  локализации; на реальном 128-seed particle filter решения 7.178 — pooled
  RMSE 10.35 → 10.06 на 40 отложенных train-скважинах).
- **Bimodal posterior-mean hedge**: работает только при явном гейтинге на
  реально неоднозначные случаи (иначе ухудшает результат); в честной
  production-реализации (без доступа к правде) выигрыш не подтвердился —
  не включён в финальную версию.

Реальный паблик-лидерборд: топ-1 ≈ 5.26, медиана ≈ 9.86 (RMSE в футах).
